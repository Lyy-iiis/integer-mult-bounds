The constructive positive result is a query-core polynomial inverse-pair
interface: using the actual inverse of the same child gives correct constant
term and degree at most recursive depth. Independent opposite-orientation
substitution fails the constant-term test even when its Laurent degree is
only linear. This is not a native compiler or a new bound.

[PROOF.md](PROOF.md) separates these facts from source chronology and the
Bini tensor-power cost issue. The [toy proof](child/FORMAL-DEGREE.md) includes
an all-depth invariant and exact finite corroboration. [SOURCES.json](SOURCES.json)
records inherited source identities and attribution.

Replay the two standard-library checks, writing outside this frozen package:

```sh
python3 -I -O -B check_source_degree.py \
  --source-root /path/to/integer-mult-bounds \
  --out /fresh/SOURCE-DEGREE.json
python3 -I -O -B child/check_degree.py --out /fresh/DEGREE-RECEIPT.json
```

The first command alternatively accepts `--source-word` with the exact pinned
`ACTUAL-WORD.json.gz` file. It reads only that external file. It retains both
helper sets and all owned clears, and gives the structural envelope
`D_next<=23 D` for homogeneous nested **raw units**. This is an upper bound,
not actual degree and not the ordinary fixed-N uniform compiler recurrence.
The toy checker reads no external source and uses exact standard-library
rational arithmetic. Neither checker imports the producer's evaluator.

The source word's compressed SHA256 is fixed for authentication. The JSON
receipts have semantic payloads; changing their whitespace is not a scientific
change. The checked mathematical identities, scope and all recorded values
must remain unchanged.

Open next questions: extend the actual inverse-pair invariant to the complete
native supplier, including all helpers and owned fields; or exhibit globally
consistent ordered matching and charge its coefficient extraction. A separate
triangular-matching investigation is not part of this frozen package.
